> Desenvolvi um projeto web simples com foco em operações CRUD, onde o usuário pode criar, visualizar, editar e excluir avaliações de álbuns. A aplicação também permite curtir músicas, que ficam armazenadas em uma lista personalizada, além de manter uma lista de álbuns que desejo ouvir futuramente, acessando a aba meu perfil o usuário poderá acessar o historico das ações feitas na aplicação. O projeto foi construído com HTML, CSS e JavaScript, utilizando Bootstrap para a estilização e responsividade. Os dados são consumidos a partir de um JSON previamente estruturado, contendo informações dos álbuns. Para a reprodução das músicas, integrei o iframe do Spotify, permitindo que o usuário escute diretamente pela aplicação. As interações foram pensadas para serem intuitivas: ao passar o mouse sobre as capas dos álbuns, surgem opções como avaliar, curtir e adicionar à lista. O objetivo do projeto foi praticar conceitos fundamentais de desenvolvimento web, manipulação de dados e interação com o usuário.
